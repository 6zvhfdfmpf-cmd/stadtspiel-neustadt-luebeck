# StadtSpiel – Stadtplanung spielerisch begreifen

**Prototyp für Schulen**  
Stadtplanung am Beispiel von **Neustadt in Holstein** und **Lübeck** erlebbar machen.

## Idee

Zwei Städte, 30 km entfernt – und doch ganz unterschiedliche Maßstäbe:

| | Neustadt in Holstein | Lübeck |
|---|---|---|
| Einwohner | ~16.000 | ~217.000 |
| Besonderheit | Historische Altstadt + Hafenwestseite-Sanierung | UNESCO-Welterbe + Lübeck 2030 |
| Fokus | Gestaltungssatzung, Klimaziel 2035, Wärmeplanung | Mobilitätswende, hitzesensible Planung |

In diesem Serious Game werden Schüler:innen zu Stadtplaner:innen. Sie treffen Entscheidungen zu Wohnraum, Grün, Verkehr und Denkmalschutz – einmal im kleinen Maßstab (Neustadt), einmal im großen (Lübeck).

## Spielen

Öffne die Datei **[index.html](index.html)** im Browser oder nutze GitHub Pages.

→ [Live spielen (nach Aktivierung von GitHub Pages)](https://6zvhfdfmpf-cmd.github.io/stadtspiel-neustadt-luebeck/)

## Was du im Spiel tust

1. Wähle den Maßstab (Neustadt oder Lübeck)
2. Bearbeite 5 reale Planungssituationen
3. Treffe Entscheidungen und sieh die Auswirkungen
4. Erhalte am Ende eine Auswertung zu Balance, Nachhaltigkeit und Konflikten
