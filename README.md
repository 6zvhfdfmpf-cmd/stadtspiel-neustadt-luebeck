# StadtSpiel – Stadtplanung in Neustadt in Holstein

**Prototyp für Schulen**  
Stadtplanung spielerisch begreifen am Beispiel von **Neustadt in Holstein**.

## Idee

Neustadt in Holstein liegt an der Lübecker Bucht: rund 16.000 Einwohner, historische Altstadt, Hafen und Ostsee. In diesem Serious Game werden Schüler:innen zu Stadtplaner:innen. Sie treffen Entscheidungen zu Wohnraum, Grün und Klima, Verkehr, Tourismus und Denkmalschutz – und sehen, wie Zielkonflikte entstehen.

Die Situationen sind an reale Themen der Stadt angelehnt (unter anderem Hafenwestseite, Wärmeplanung, Gestaltungssatzung, Ferienwohnungen und Hochwasserschutz). Die Inhalte sind vereinfacht und für den Unterricht aufbereitet; sie ersetzen keine amtliche Planung.

## Spielen

Öffne die Datei **[index.html](index.html)** im Browser. Das Spiel ist eine statische Website (HTML, CSS, JavaScript) und läuft auch auf dem Handy.

## Was du im Spiel tust

1. Schau dir die stilisierte Karte von Neustadt an
2. Bearbeite sieben Planungssituationen
3. Triff eine Entscheidung, ohne vorher die Wertung zu sehen
4. Sieh danach die Auswirkungen auf Wohnen, Grün & Klima und Wirtschaft
5. Erhalte am Ende eine Auswertung, bei der auch die Balance zählt

## Für Schulen

- Open Source (MIT)
- Sofort testbar, auch offline (Schriftarten brauchen ggf. eine Internetverbindung)
- Anpassbar (Szenarien und Texte in `js/data.js`)
- Gut geeignet für Politik, Geografie, Wirtschaft oder Projektwochen

## Technik

- Reines HTML, CSS und JavaScript (kein Framework)
- Mobil zuerst gestaltet
- Keine API-Schlüssel, keine externen Kartendienste
